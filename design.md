Design Language — Mecliw Medical Clinic
Reference: Mecliw - Medical Clinic Website landing page (1920 x 7000px)

1. Color Palette
   Role Hex RGB Usage
   Primary (Teal) #08474B rgb(8, 71, 75) Buttons, CTAs, icon backgrounds, footer, dark accent areas
   Background #EFFEFF rgb(239, 254, 255) Page background — icy mint/near-white
   Surface / White #FFFFFF rgb(255, 255, 255) Cards, button outlines, input fields, white text on dark
   Text Primary #1C1C1C rgb(28, 28, 28) All body and heading text on light backgrounds
   Neutral Gray #D9D9D9 rgb(217, 217, 217) Image placeholders, dividers
   Muted Gray #C4C4C4 rgb(196, 196, 196) Secondary placeholders
   Color Philosophy
   Restrained two-tone system: Deep teal (#08474B) against an icy mint background (#EFFEFF) with white surfaces. No gradients. No multi-color accents.
   Dark teal is reserved for interactive elements, icons, and the footer — never used as a large section background mid-page.
   Text is uniformly near-black (#1C1C1C) on light backgrounds and pure white (#FFFFFF) on dark backgrounds.
2. Typography
   Typeface
   Urbanist — single family, Regular weight throughout. The entire design uses one weight to achieve a calm, modern, clinical feel. Hierarchy is created through size contrast alone, not weight.

Typography Rules
No bold, no italic — hierarchy is purely size-driven
Text case: Title Case used only for navigation links, labels, and small UI text. Headings and body remain sentence/original case.
Line height: Auto (default) throughout — generous and natural
Letter spacing: 0% (default) — no tracking adjustments 3. Layout & Grid
Canvas & Content Area
Page width: 1920px
Content width: 1455px (centered, ~232px margin on each side)
Section gap: ~151px vertical spacing between every section (consistent rhythm)
Header to hero gap: 24px (tight coupling)
Section Structure
The page follows a strict vertical rhythm with 9 distinct sections:

Header — Navigation bar (logo + nav links + CTA)
Home / Hero — Large headline + stats row + featured image grid
Why Choose — Three-column stat cards with percentages
About Us — Full-width section heading + description paragraph
Our About — Two-column layout (text + image)
Services — 2x2 card grid with image + text
Contact — Highlighted CTA banner with rounded container
Testimonial — Horizontal scrollable testimonial cards
Footer — Dark teal full-width footer with link columns
Grid Patterns
Two-column split: Used for About sections (text left, image right or vice versa)
2x2 card grid: Used for Services — cards are ~705px wide with ~45px gap
Three-column stat row: Used for "Why Choose" metrics
Horizontal scroll: Used for testimonials (cards extend beyond content width) 4. Corner Radius
Element Type Radius Usage
Buttons (pill shape) 100px (full pill) All CTAs and nav buttons
Large containers / Cards 15px Section containers, service cards, image cards
Small cards / Stat boxes 10px Stat highlight cards
Icon containers 4px Small square icon frames
Radius Philosophy
Buttons are always fully rounded (pill shape) — this is a signature of the design
Content cards use a consistent 15px radius
No sharp corners (0px) anywhere in the content area — only the full-bleed page frame is square 5. Buttons & CTAs

Drop shadow (sparingly): 0px 4px 30px rgba(0, 0, 0, 0.1) — used on select elevated cards
No blur effects on the page
No gradients anywhere
The design relies on color contrast and spacing for depth, not shadows 9. Footer
Background: #08474B (primary teal) — full page width
Text: White (#FFFFFF)
Structure: Multi-column link layout (Menu, Links, Contact) with subscribe input
Typography: Footer headings ~32px, body links ~21px
Text case: Title Case for all footer text 10. Design Principles Summary
Monochromatic restraint — Two colors (teal + icy mint) with black text. No decoration colors.
Size-only hierarchy — Single font family, single weight. Size does all the work.
Pill-shaped interactions — Every clickable element is a full-radius pill.
Generous breathing room — 151px between sections, large content margins, spacious cards.
Soft modern clinical — Rounded corners everywhere (15px cards, pill buttons), icy palette, clean.
Consistent rhythm — Equal section gaps create a metronome-like vertical cadence.
Flat design — Minimal shadows, no gradients, no overlays. Depth from whitespace and color blocking.
Image-forward — Large rounded image blocks integrated with text, not decorative.
Quick Reference for New Designs
When creating new pages or components in this system:

Use Urbanist Regular exclusively
Background: #EFFEFF | Primary: #08474B | Text: #1C1C1C
All buttons: pill-shaped (radius 100px), teal or white
Cards/containers: 15px radius
Section spacing: ~150px
Content width: 1455px centered on 1920px canvas
Keep it flat — no gradients, no heavy shadows
Headline sizes: 74–110px for impact, 28–42px for card-level
Body text: 18px
